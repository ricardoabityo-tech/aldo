# LEGAL INSIGHT - Platform Layanan & Edukasi Hukum Terpadu Indonesia

Platform website dan web application **Legal Insight** dibangun secara profesional menggunakan bahasa pemrograman **C# / ASP.NET** dan teknologi web modern, dirancang khusus agar dapat dibuka, dijalankan, dan dikembangkan secara langsung melalui **Microsoft Visual Studio** maupun **Visual Studio Code**.

Proyek ini telah direvitalisasi dengan identitas visual resmi **NAVY WHITE GOLD** berdasarkan logo resmi Legal Insight (*Strategy & Foresight*).

## 🏛️ Fitur & Modul Utama Platform

1. **Halaman Utama (Homepage)**
   - Headline resmi: *"Strategi Hukum yang Tepat, Masa Depan yang Lebih Terarah."*
   - Subheadline resmi: *"Legal Insight hadir sebagai platform layanan hukum digital yang membantu masyarakat mendapatkan akses konsultasi, informasi, dan solusi hukum secara profesional."*
   - Dua tombol utama: **Mulai Konsultasi** (Navy) & **Temukan Advokat** (Outline Navy).
   - Profil komprehensif Legal Insight sebagai platform LegalTech terintegrasi di Indonesia.
   - 6 Pilar Layanan Utama (Konsultasi Hukum, Profil Advokat, Dokumen Hukum, Edukasi Hukum, Legal Academy, Berita Hukum).
   - Mesin pencari masalah hukum interaktif (Global Search).
   - Alur kerja 4 langkah bernomor Navy & Gold.
   - Metrik statistik platform (150+ Advokat Mitra, 15.000+ Konsultasi Selesai, 98.8% Kepuasan Klien).

2. **Profil Advokat**
   - Direktori advokat mitra terverifikasi berlisensi PERADI & KAI.
   - Filter multi-kriteria: Bidang Spesialisasi, Wilayah/Kota, dan pencarian nama.
   - Kartu profil putih bersih dengan badge spesialisasi Gold dan tombol konsultasi Navy.
   - Halaman Modal Detail Advokat lengkap: Foto profil, Nomor Induk Advokat (KTA), Riwayat Pendidikan, Pengalaman Kerja, Sertifikasi, Pilihan Layanan & Tarif, Jadwal Slot Ketersediaan, dan tombol pemesanan langsung.

3. **Konsultasi Hukum (End-to-End Booking & Live Room)**
   - Alur 4 langkah wizard reservasi:
     1. Konfirmasi & pemilihan advokat mitra.
     2. Formulir pengisian masalah hukum (kategori perkara, judul, uraian kronologi, upload lampiran dokumen bukti).
     3. Pemilihan metode (Chat 45m, Video Call 60m, Tatap Muka 90m) & slot jadwal.
     4. Rincian biaya & metode pembayaran aman (QRIS instan, Virtual Account BCA/Mandiri).
     5. Konfirmasi pembayaran instan & notifikasi sistem otomatis.
   - **Ruang Konsultasi Aktif**: Live chat room interaktif antara klien dan advokat, tombol simulasi Video Call, dan panel catatan *Legal Opinion* (Resume Pendapat Hukum) bertanda logo resmi yang dapat langsung dicetak atau diunduh sebagai file PDF.

4. **Layanan Dokumen Hukum (Drafting & Review)**
   - Katalog dokumen hukum populer: PKWT Ketenagakerjaan, Non-Disclosure Agreement (NDA) bilingual, Perjanjian Kerjasama (MoU), Surat Somasi Resmi, Perjanjian Sewa Menyewa, dan Legal Opinion.
   - Pilihan 2 jenis layanan: **Penyusunan Baru (Drafting)** atau **Peninjauan (Review)** dengan audit risiko hukum.
   - Pilihan kecepatan pengerjaan: Reguler (2-3 hari) atau Express (24 jam).
   - Kalkulasi estimasi biaya otomatis dan generator unduh draf dokumen final.

5. **Edukasi Hukum, Legal Academy, dan Berita Hukum**
   - **Edukasi Hukum**: Panduan hukum bahasa awam (Langkah Hukum Penipuan Online UU ITE, Hak Karyawan PHK PP 35/2021, Jual Beli Tanah Aman BPN).
   - **Glosarium Hukum**: Kamus istilah hukum interaktif (Wanprestasi, PMH Pasal 1365 KUHPerdata, Asas Legalitas, Ultimum Remedium, Mediasi).
   - **Legal Academy**: Pelatihan hukum bersertifikat dan webinar bersama praktisi advokat senior, lengkap dengan silabus, jadwal, dan pendaftaran e-ticket instan.
   - **Berita Hukum**: Analisis putusan Mahkamah Agung & MK, regulasi perundang-undangan baru, dan isu hukum aktual.

6. **Dashboard Multi-Role (Pengguna, Advokat, dan Admin)**
   - Desain profesional dengan **Sidebar Navy** (`#0B192D`) dan **Area Konten Off-White** (`#F8F7F3`).
   - Logo resmi Legal Insight pada sidebar.
   - Menu teks putih dengan indikator aktif beraksen Gold.
   - Kartu statistik berlatar putih dengan heading Navy dan angka tegas.
   - Responsif dengan drawer navigasi pada layar mobile.
   - Role switcher terintegrasi untuk beralih antara Klien, Advokat, dan Administrator.

7. **Modal Login & Registrasi**
   - Menampilkan logo resmi Legal Insight.
   - Desain kartu putih minimalis, tombol submit Navy, dan aksen navigasi Gold.

## 💻 Cara Membuka & Menjalankan di Visual Studio

### Opsi 1: Menggunakan Microsoft Visual Studio (Versi 2012, 2015, 2017, 2019, 2022)
1. Buka folder proyek `d:\website` di File Explorer.
2. Klik ganda pada file **`LegalInsight.sln`** untuk membuka solusi di Visual Studio.
3. Tekan **F5** (atau klik menu **Debug -> Start Debugging** / tombol hijau **Start**).
4. Visual Studio akan mengompilasi program C# dan server akan otomatis meluncurkan browser ke `http://localhost:5000`.

### Opsi 2: Menggunakan Visual Studio Code (Live Server & Browser Debugger)
1. Buka folder `d:\website` di Visual Studio Code (`code .`).
2. Pasang ekstensi **Live Server** (oleh *Ritwick Dey*) dari VS Code Marketplace (`ritwickdey.liveserver`).
3. Klik tombol **"Go Live"** di status bar kanan bawah VS Code (atau klik kanan pada `index.html` -> **"Open with Live Server"**).
4. Website akan terbuka otomatis di Microsoft Edge pada `http://localhost:5500`.
5. Untuk melakukan debugging interaktif, tekan **F5** (konfigurasi debugger browser `msedge` pada `launch.json`).

### Opsi 3: Satu Klik Langsung di Windows (Batch Launcher)
1. Cukup klik ganda file **`Jalankan_Website.bat`**.
2. Skrip akan membuka server lokal dan meluncurkan browser langsung ke `http://localhost:5000`.

### Opsi 4: Buka Langsung di Web Browser
Anda juga dapat langsung membuka file **`index.html`** di browser manapun (Google Chrome, Microsoft Edge, Firefox). Seluruh fitur interaktif dan penyimpanan lokal (*localStorage*) berfungsi penuh tanpa instalasi server tambahan.
